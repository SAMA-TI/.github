## 🎯 Sobre SAMA

El **Sistema de Alerta y Monitoreo de Antioquia (SAMA)** es un proyecto gubernamental implementado para conocer y reducir el riesgo de desastres por la ocurrencia de inundaciones, crecientes súbitas y avenidas torrenciales en el departamento de Antioquia, Colombia.

**SAMA-TI** es el equipo de Tecnología e Innovación encargado del desarrollo de software y análisis de datos que impulsa esta importante iniciativa de protección ciudadana.

## 🛠️ Qué Hacemos

Nuestro equipo se especializa en:

- 💻 **Desarrollo de Software Web y Móvil** para sistemas de monitoreo y alerta
- 📊 **Análisis de Datos** en áreas críticas: 
  - Meteorología
  - Hidrología
  - Deslizamientos de tierra
  - Gestión del riesgo
